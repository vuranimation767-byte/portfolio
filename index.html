About

Block Builder is a solo plugin studio for Minecraft servers. I build Paper-first game systems — bounty economies, time-based SMPs, hardened GUIs — backed by crash-safe storage, validated configs and real tests. If a player can break it at 3am, the ledger still has to balance.

BountySystem

Place bounties on players' heads with real escrow — diamonds or Vault money — and a killer's payout that survives a crash.

Features

  • Seven-menu GUI board, reachable with /bounty
  • Physical diamond escrow or Vault economy
  • Crash-safe SQLite WAL ledger — every payout audited
  • Hardened menus: the GUI can never move money itself
  • Config validation — a bad edit leaves the last good config running

Commands to type

/bounty
/bounty list
/bounty place <player> <amount>
/bounty cancel <id>
/bounty reload                (admin)
/bounty admin ledger          (admin)
/bounty admin resolve <id> refund|reject

LifeClock

An SMP where every player lives on borrowed time. Steal it in PvP, lose it to death, revive it with a sacrifice.

Features

  • BossBar HUD counts your remaining life — green, yellow, red heartbeat
  • Kill a player, take a slice of their clock
  • Death shortens the clock; respawning doesn't reset the debt
  • Revive Totem recipe — five hours of sacrifice to open the GUI
  • 27-slot ghost-revive menu with compass search

Commands to type

/lifeclock add <player> <time>
/lifeclock remove <player> <time>
/lifeclock set <player> <time>
/lifeclock check <player>
/lifeclock revive <player>    (admin)
/withdraw <time>
