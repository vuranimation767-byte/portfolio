Privacy & terms

Last updated 25 October 2026

This is a personal portfolio for Block Builder, a solo Minecraft plugin developer. It is a static site: there are no accounts, no comments, no analytics and no advertising.

Hosting

The site is served by GitHub Pages. GitHub may process standard request data — such as your IP address, browser and the pages you request — to deliver the site and keep it secure. That processing is covered by the GitHub Privacy Statement.

What this site stores

The only thing stored in your browser is your light or dark theme choice, kept in localStorage under the key theme. It never leaves your device, and clearing site data removes it.

The admin editor at admin.html is a separate tool for the site owner. Drafts and publish settings it saves stay in that browser; they are not part of the public site.

Videos

Demo videos are hosted on YouTube. Nothing is requested from YouTube until you press play on a video. When you do, the video loads from youtube-nocookie.com, and YouTube (Google) may receive your IP address and set cookies or similar storage under its own policies. The Google Privacy Policy applies from that point. “Open on YouTube” links also take you to YouTube.

Downloads

Plugin files are hosted on GitHub Releases. Downloading one takes you to GitHub, where the GitHub Privacy Statement and GitHub’s terms apply. Any licence included in the plugin’s repository also applies.

Using the plugins

Plugins are provided as-is, without warranty. Back up your server and its data before installing or updating anything. You are responsible for testing a plugin on your own server and for how it is configured.

Content and trademarks

Plugin names, code and site content belong to Block Builder unless a repository says otherwise. Minecraft is a trademark of Mojang Studios. This site is an unofficial portfolio and is not affiliated with, endorsed by or sponsored by Mojang Studios or Microsoft.

Changes

These terms may be updated as the site changes. The date at the top shows the latest revision.
